# Shagiththiah Kirupakaran — Portfolio

Personal portfolio with About, Projects, and Blog navigation, a profile portrait, social links, and downloadable CV.

## GitHub Pages

The portfolio is hosted at **https://shagiththiah.github.io/** from the public repository `Shagiththiah/shagiththiah.github.io`.

GitHub Pages publishes the **main** branch's repository root. The explicit `index.html` serves the portfolio and loads its assets from `docs/`. Push updates to this repository to deploy changes automatically.

Do not add a CNAME for a `github.io` address; that address follows the owner and repository names.

## Preview and edit

Run `python -m http.server 8080` in this directory and open http://localhost:8080.

- `index.html`: homepage biography, links, projects, and Blog content
- `docs/index.html`: standalone copy for viewing the docs directory directly; keep content synchronized with the homepage
- `docs/style.css`: styles and responsive layout
- `docs/script.js`: tab navigation and project expansion
- `docs/assets/`: profile photo, project image, and CV

The Blog tab is ready for future posts. The photo uses CSS framing; the original image file is preserved.
